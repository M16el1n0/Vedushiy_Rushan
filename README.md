# Рушан — ведущий праздников

Сайт-портфолио ведущего праздников: свадьбы, юбилеи, корпоративы, Дед Мороз, живая музыка.

## Структура

```
index.html          — весь сайт (HTML + CSS + JS в одном файле)
fonts/              — шрифт Playfair Display (woff2 + ttf), подключён локально
images/             — фотографии для hero, проектов и галереи
```

## Как открыть

Просто откройте `index.html` в браузере. Внешних зависимостей нет — интернет не нужен.

## Как выложить в интернет (GitHub Pages, бесплатно)

1. Создайте репозиторий, загрузите **содержимое** папки `rushan-site` (index.html, fonts/, images/) в корень репозитория.
2. Settings → Pages → Source: `Deploy from a branch` → Branch: `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

> Важно: папка `fonts/` должна лежать рядом с `index.html`, иначе браузер подставит стандартный шрифт.
